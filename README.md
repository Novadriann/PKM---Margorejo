🌱 PKM - Margorejo: Sistem Monitoring Tanah IoT
PKM-Margorejo adalah sebuah program pembuatan alat pemantauan kualitas tanah berbasis Internet of Things (IoT). Proyek ini dirancang untuk membaca dan menganalisis parameter penting kesuburan tanah secara real-time menggunakan sensor NPK, yang kemudian datanya dikirimkan ke server agar dapat dipantau melalui dashboard web dari mana saja dan kapan saja.

📖 Deskripsi Proyek
Kualitas unsur hara dalam tanah sangat menentukan keberhasilan dan produktivitas hasil pertanian. Sistem ini hadir sebagai solusi teknologi cerdas untuk membantu pemantauan lahan secara presisi. Alat ini akan membaca kadar Nitrogen (N), Fosfor (P), dan Kalium (K) langsung dari lahan, memproses data melalui mikrokontroler, dan memancarkannya ke jaringan internet. Dengan integrasi web, pemantauan tidak lagi terbatas oleh jarak dan waktu.

✨ Fitur Utama
Pembacaan NPK Akurat: Menggunakan sensor NPK tanah untuk mendeteksi unsur hara penyubur tanaman.

Konektivitas Nirkabel: Pengiriman data dari lahan ke server memanfaatkan protokol nirkabel secara efisien dan cepat.

Pemantauan Real-Time 24/7: Pembaruan data pembacaan sensor secara terus-menerus.

Web Dashboard Integrasi: Akses antarmuka pemantauan responsif yang dapat diakses melalui perangkat komputer maupun ponsel cerdas di mana pun.
